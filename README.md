# HangMan (Vešala)

Jednostavna **igra vešala** u čistom **JavaScriptu** (bez bundlera).

## Struktura

- `index.html` – ulazna stranica  
- `src/` – logika (`index.js`, `Veshala.js`)  
- `assets/` – statički resursi  

## Kako pokrenuti

1. Otvori `index.html` direktno u browseru, **ili**  
2. Pokreni lokalni statički server iz korena repozitorijuma, npr.:

```bash
npx serve .
# ili: python -m http.server 8080
```

Zatim otvori prikazanu lok adresu u browseru.

## Napomena

Projekat koristi module / relativne putanje; ako otvaranje fajla „file://“ pravi probleme, korak 2 je pouzdaniji.
